# 🧰 Frontend Playground – Vanilla JS Tools Collection

Welcome to my collection of **small, handy, static web tools**!  
Every project in this repository is built with pure **HTML5, CSS3, and Vanilla JavaScript** – no libraries, no frameworks, no build tools. Just open and run.

## 📌 Overview
This repository serves as a portfolio of my front-end development skills, focusing on:
- **DOM Manipulation**
- **Local Storage & State Management**
- **Fetch API & Asynchronous JavaScript**
- **Responsive UI/UX Design**
- **ES6+ JavaScript**
